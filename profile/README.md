## Como operamos

- **Stack:** Next.js + Django/DRF, PostgreSQL, VPS próprio com Cloudflare na borda.
- **Entrega:** GitHub Actions (test + build + deploy), healthcheck de origin e edge a cada deploy.
- **Qualidade:** TypeScript estrito, testes como gate de CI, copy sem travessão, SEO/GEO/AEO de primeira (sitemap, JSON-LD, `llms.txt`).

## Portfólio

Além dos sites acima: socorro veicular 24/7, automações WhatsApp, rastreamento, saúde e serviços locais — cada produto no seu repositório, cada deploy auditável.
